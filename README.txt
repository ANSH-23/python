🎮 Gaming Score Data Analyzer
--------------------------------
This project analyzes and visualizes player performance data using Python.

📂 Files:
- analyzer.py → Main program
- scores.csv → Sample player data

🧠 Features:
- Calculates average, highest, lowest, and total scores
- Generates leaderboard ranking
- Displays bar, line, and pie charts for visualization
- Uses NumPy for computation and Matplotlib for graphs

🔧 How to Run:
1. Install libraries:
   pip install numpy matplotlib
2. Run the project:
   python analyzer.py

📊 Output:
- Console report of player statistics
- Graphical charts showing performance trends and rankings
